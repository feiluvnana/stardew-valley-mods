# 🎒 ExtendedStackable

**ExtendedStackable** unlocks stackability for items that are normally restricted to single-inventory slots in **Stardew Valley 1.6+**.

---

## ✨ Features

- **Stack Fishing Tackle & Lures up to 999:**
  Allows Trap Bobbers, Curiosity Lures, Cork Bobbers, Dressed Spinners, and other full-durability tackle to stack seamlessly in your backpack and chests.

- **Stack 1.6 Trinkets up to 999:**
  Stack identical Fairy Boxes, Frog Eggs, Magic Quivers, Basilisk Paws, and Ice Rods.

- **Stack Rings & Accessories up to 999:**
  Combine duplicate rings (Iridium Bands, Lucky Rings, Crabshell Rings) into clean inventory stacks.

- **Stack Furniture & Decors up to 999:**
  Store multiple chairs, tables, lamps, and decorative pieces in a single slot.

- **Stack Boots, Clothing & Hats up to 999:**
  Clean up wardrobe storage by stacking identical apparel and footwear.

- **Configurable Max Stack Size (`MaxStackSize: 999`):**
  Adjust the global maximum stack ceiling or toggle individual item categories on and off.

---

## ⚙️ Configuration (`config.json`)

```json
{
  "MaxStackSize": 999,
  "EnableTackleStacking": true,
  "EnableTrinketStacking": true,
  "EnableFurnitureStacking": true,
  "EnableRingStacking": true,
  "EnableClothingAndHatStacking": true,
  "EnableBootsStacking": true
}
```

Configurable in-game via **Generic Mod Config Menu**.
